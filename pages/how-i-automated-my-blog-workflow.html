How I Automated My Blog Workflow

I wanted to keep my personal website in my own complete control and didn't want to rely on any static site generator to do the work for me. After only creating the first 5 pages, I've noticed how useful one might be. That's the reason I'm somewhat building my own.

My current setup works through a texts.html file where a list of all the texts I wrote is stored in a table with hyperlinks to the specific ones. The texts are stored in the directory pages/.

The idea is simple. I use neovim for editing all my files and in neovim you're able to create your own functions. I want to run a function in neovim (:NewText) which prompts me to put in a name for a title. It creates a file, fills it and creates an entry in the texts table on its own. This seems fairly simple.

The first thing I did was creating such a boilerplate html file. I create a new folder templates/ and put the boilerplate as text.html inside of it.

Then I created a new blog.lua file in my lua/config/ directory in neovim and included it into my lua/config/lazy.lua:

require("config.blog")

Then I added a new_text() function that reads the date and asks the user for a title and then creates the text file and the table entry: 

 function M.new_text()
  vim.ui.input({
    prompt = "Title: ",
  }, function(title)
    if not title or title == "" then
      return
    end

    local slug = slugify(title)
    local filename = slug .. ".html"
    local filepath = pages .. "/" .. filename
    local date = os.date("%Y-%m-%d")

    if vim.fn.filereadable(filepath) == 1 then
      print("File already exists.")
      return
    end

    local lines = vim.fn.readfile(template)

    for i, line in ipairs(lines) do
      line = line:gsub("{{TITLE}}", title)
      lines[i] = line
    end

    vim.fn.writefile(lines, filepath)

    local html = vim.fn.readfile(texts)

    local row = {
      "        ",
      "          ",
      '            ',
      "              " .. title,
      "            ",
      "          ",
      '          ' .. date .. "",
      '          ' .. date .. "",
      "        ",
    }

    for i, line in ipairs(html) do
      if line:find("") then
        for j = #row, 1, -1 do
          table.insert(html, i + 1, row[j])
        end
        break
      end
    end

    vim.fn.writefile(html, texts)

    vim.cmd("edit " .. filepath)

    print("Created " .. filename)
  end)
end

After creating that I restartet neovim and created my first text page like that, but there was still something I wanted to do. In my text table I have a date for created and edited and I also wanted to create a function for updating the edited date, so I did that: 

function M.update_edited()
  local filepath = vim.fn.expand("%:p")

  if not filepath:find("/pages/") then
    return
  end

  local filename = vim.fn.expand("%:t")
  local date = os.date("%Y-%m-%d")

  local html = vim.fn.readfile(texts)

  local found = false

  for i, line in ipairs(html) do
    if line:find("./pages/" .. filename, 1, true) then
      found = true

      for j = i, math.min(i + 10, #html) do
        if html[j]:find('') then
          if html[j + 1] and html[j + 1]:find('') then
            html[j + 1] = '          ' .. date .. ""
            break
          end
        end
      end

      break
    end
  end

  if found then
    vim.fn.writefile(html, texts)
    print("Updated edited date")
  end
end
