Which GNU/Linux Distro Is Right For Me?

tl;dr

  1. The 7 needs and wants from a distro should be followed if possible
  2. One of the no glibc ones probably fits it well as discussed here.

I want to improve my laptop. That doesn't always mean adding new features (mostly it doesn't) and it also doesn't mean to use the newest, flashiest or most elegant solution there is. Sometimes it just means to use the simplest tools you need and nothing more.

I know for a fact, that I don't meet that criterea right now and thats the reason I want to improve it. So lets start by examaning what currently lies infront of my feat.

My operating system GNU/Linux I'm using is Arch Linux. It's the only distro I've really used daily and I've never had a problem with it. The reason I chose it as my first distro, is because it seemed hard, I liked the minimalism, the newest packages and learning something about GNU/Linux.

But times have changed. Now I wouldn't see Arch as a minimal distro per se, I wouldn't say it's hard and it already did it's job of teaching me GNU/Linux. The step is a new one to a new level of distros. Some that come to mind for many are:

I split all the distros I was able to find (that where actively maintained and somewhat in line with my goals) into one of three categories: minimalist, source-based and different. The "different" category contains all the distros that aren't minimalist by design or philosophy and not source-based. If you know a distro not listed, but appropriate for this list open a pull request. I'd be happy to learn about it.

As you may see, for all of them (excep NixOS) you have the option to run it without systemd and for most you have the option to use another c library than glibc. I haven't tried most of them yet, but this somewhat serves as a list for what i'd like to have a look at in the future.

To understand which of them I find more interesting than others I first have to talk about my needs and wants from a linux distro.

The distro needs to only run / compile what I tell it to

By that I mean, that I can change compiler flags and everything else that comes with a source based distro I prefer it generally over a binary distro.

The distro should be minimal and understandable by design (do one thing and to it well)

The regular suckless and Unix philosophy also applies here. In particular I mean, that I can understand the whole system without there being a black box. For that to be possible the distro can't be to complex and should be kept minimal and split up in to many small parts. As far as I know Crux and KISS are doing a good job in maintaining that.

The distro should be hackable

The perfekt world here is of course LFS, but it doesn't need to be it to have similar possiblities. The requirments should be that I can change the init system, coreutils, bootloader, desktop environment, etc. It should not get into my way and stop me from doing something, even if it can break things or if it's hard to pull of.

The distro should enforce strict rules (that I've defined)

NixOS is a distro that enforces probably the strongest rules, but they are distro and not user defined. The perfekt thing would be NixOS where I can still hack around things I specifically want to do and disable the "safeguards".

The distro should be reinstallable in reasonable time

LFS is not installable on a new laptop in a reasonable amount of time. Gentoo probably isn't either, but by far not that bad. NixOS is probably one of the fastest, because all of its config is decleratively defined. NuTyX, Venom and Exherbo are probably also good at this.

The maintainers should be able to say no (staying true to their philosophy)

If a new shiny technology appears or a new feature is suggested, they should be able to say no in favor of the distro and its minimalism. That also means having good quality control and a lot of testing to ensure that the project will last.

The packages should be up to date

There should be a balence between git main and out of date. As far as I know T2 Linux does a very good job in maintining package up-to-dateness.

What will I use now?

To be fair I don't know yet. All the interesting one have the option to be used without glibc. NixOS or the unmarked distros are probably not the ones I'll use in the future. I also won't daily drive LFS, because of the time required to set everything up and probably also not Adelie, because after more then 10 years it's still in beta.

From all the other one especially Gentoo, Crux, KISS Linux, Exherbo and Chimera Linux seem interesting. I don't know what exactly I'll choose, but it's very likely to be one of them. If you have any suggestion or usage experience with any of them I'd be very thankful for sharing that with me.
